Badge de status de pedido/remessa/divergência — sempre com texto; use em listas, títulos de documento e tabelas.
```jsx
<StatusBadge status="em_transito" />
<StatusBadge tom="transito">12 dias</StatusBadge>
```
- solicitado/aprovado → azul, em_transito → âmbar, recebido/encerrado → verde, com_divergencia → vermelho, rascunho/cancelado → cinza.
