Gráfico de linha com grade tracejada, eixos em mono e tooltip grafite no hover; use para séries diárias (remessas enviadas × recebidas).
```jsx
<GraficoLinha rotulosX={['01/09','02/09']} series={[{nome:'Enviadas',cor:'var(--cor-marca)',valores:[4,6]},{nome:'Recebidas',cor:'var(--cor-estrutura)',valores:[3,5]}]} />
```
