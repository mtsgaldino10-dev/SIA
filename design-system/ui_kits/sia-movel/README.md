# Warefly — UI kit celular
Telas mobile first (<900px): cabeçalho grafite + barra inferior com borda cobre (`components/Layout.tsx`). Abre em [`referencia/ui_kits/sia-movel.html`](../../referencia/ui_kits/sia-movel.html).
- **InicioBase** — "Minhas bases" com etiquetas compactas 2×2 e remessas a caminho (Inicio.tsx → MinhasBases).
- **Receber** — contagem por item, motivo quando falta, quem contou, data, foto obrigatória, ação fixa no rodapé (remessas/Receber.tsx + Conferencia.tsx). A tabela do app vira cartões por item no celular.
- **Feito** — confirmação.
